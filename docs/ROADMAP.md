# Roadmap

Each milestone ships as one or more PRs with tests, and must beat the original game's
numbers from milestone 0 before it counts as done.

Reference source: OpenJK at `260c59c2907187af555a676fe0cc798893bf7757` (2026-09-29).
`code/` is single-player, `codemp/` multiplayer; about 1M lines of C/C++ between them.

| # | Milestone | Done when |
|---|-----------|-----------|
| 0 | **Baseline and setup** (multiplayer FPS and load time done, frame times of world rendering on the demo's camera path done, see BASELINE.md; frame-time spikes of the full game and single-player pending): Rust workspace and local CI; measure the original game's FPS, frame-time spikes and load times on fixed scenes; screenshot-comparison tool | The original's numbers are recorded in `docs/BASELINE.md` and reproducible with one script |
| 1 | **Assets** (**done**: `crates/fs`, `crates/bsp`, `crates/image`, `crates/shader`, `crates/console`): `.pk3` archives, virtual filesystem with the original's search order, `.bsp` maps, textures (TGA, JPEG, PNG), `.shader` scripts, cvars and configs | Every file in the retail `.pk3`s parses; tests pin the results |
| 2 | **Map viewer** (started: Vulkan bring-up and offscreen rendering in `crates/render`; map surfaces, patches and stitching in `crates/world`; textured, lightmapped preview render of a map to PNG; material resolution in `crates/shader/src/resolve.rs`; stage rendering, fog, sky, deforms and flares matching all 11 reference views; surface sprites (grass) scattered and swaying as the original's, matching t2_dpred's grass; the original's visibility culling; the same camera path timed in both engines: with two frames in flight, 1.4-1.7x the original's frame rate offscreen; the map viewer `swjkja view`, which flies through a map in a window or exclusive fullscreen; presenting measured to the step (the compositor costs both engines about 1 ms, our copy to the window 0.6-0.8 ms, drawn straight into the image in a window), faster than the original in both: 1.04-1.08x in a window and 1.05-1.18x in fullscreen on an idle PC, 1.15-1.45x with a busy PC, see BASELINE.md (speed goal met); a loading screen with a progress bar, the first frame 0.26-0.35 s after the window opens; next: milestone 3): Vulkan renderer for world geometry, lightmaps, shader stages, fog, sky | Fly-through matches the original's screenshots; faster than the original on the same scenes |
